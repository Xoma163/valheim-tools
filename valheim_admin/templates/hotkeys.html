Все дополнительные горячие клавиши сборки

Назначения сверены с конфигами текущего профиля сборки. После ручной перенастройки у тебя они могут отличаться. Это список клавиатуры и мыши; обычные игровые клавиши здесь не дублируются. ЛКМ / ПКМ — левая / правая кнопка; Mouse2 — нажатие колёсика.

Общее меню

  • F10 — настройки модов и панель StoreAndCraft.

StoreAndCraft

  • . (DOT / Period) — разложить вещи по ближайшим сундукам; клавиша по умолчанию. В текущем экспортированном профиле переназначена на Q.
  • Нажатие колёсика над предметом — отправить одну стопку в сундук.
  • Левый Ctrl + нажатие колёсика — пополнить стопку под курсором из сундуков.
  • Y над предметом — подсветить ближайший сундук с ним.
  • F над предметом — включить/выключить избранное; такие предметы пропускаются при переносе.
  • Левый Alt + E при наведении — настройки сундука, таблички или поддерживаемой станции. Для сундука также работает альтернативное взаимодействие.
  • Левый Alt + R над табличкой хранения — радиус поиска сундуков этой таблички.
  • Удерживать C при подтверждении постройки молотом — забрать материалы детали из сундуков, не размещая её.
  • B при наведении на поддерживаемую станцию и закрытом инвентаре — автозаполнение; N — автоматическая отправка продукции в хранилище. Производственную автоматизацию по нашим правилам не используем. Пополнение факелов и костров разрешено.

EquipmentAndQuickSlots

  • Z / V / B — быстрые слоты 1 / 2 / 3. Для слотов 4–6 клавиши не назначены; в профиле включены три слота.
  • Левый Alt + перетаскивание фона панели — переместить панель экипировки.

InputTweaks

  • F3 — скрыть/показать HUD.
  • Shift + ЛКМ — перенести стопку между инвентарями.
  • Ctrl + ЛКМ / ПКМ — разделить стопку.
  • Перетаскивание с ЛКМ / ПКМ — распределить стопку / по одному предмету.
  • Колесо над предметом — перенос между инвентарями.
  • Q / Shift + Q над предметом — выбросить один предмет / стопку.

PlantEasily

  • С культиватором и выбранным растением: F8 — функции мода, F10 — привязка к сетке по умолчанию (в текущем профиле — F11), F6 — автоматическая пересадка после сбора.
  • Правый Ctrl + ← / → — уменьшить/увеличить число столбцов, Правый Ctrl + ↓ / ↑ — число рядов.
  • Левый Shift + E по созревшим растениям — массовый сбор, если разрешён настройками; для пересадки нужны семена.

CrewStats и SocialSystem

  • F7 — статистика CrewStats.
  • O — социальное окно SocialSystem, P — окно группы.

BetterMinimap

  • = / − — приблизить/отдалить мини-карту; работают также Shift + = / Shift + − и NumPad + / −. Дополнительные клавиши можно выключить одним переключателем в настройках мода.

Zen_ModLib

  • Q — альтернативное взаимодействие вместо Shift + E.

У MissingPieces, Stay Loaded, RememberServerPassword и серверного WebMap отдельных игровых сочетаний в этом списке нет: используются обычные действия игры или кнопки интерфейса. NPS работает автоматически.

Пересечения: Q назначена сразу StoreAndCraft, InputTweaks и Zen_ModLib, а в игре — автобегу; B — быстрому слоту и автозаполнению StoreAndCraft. F11 может также снимать скриншот игры. Учитывай контекст или переназначь клавиши через F10. У PlantEasily сетка уже перенесена с F10 на F11.
