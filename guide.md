1. [Скачать](https://r2modman.com/download-latest/) r2modman(r2modman-**Setup**-3.\*.\*.exe) и установить
2. Запустить, выбрать игру Valheim, выбрать платформу Steam
3. Нажать кнопку Import / Update → From Code, вставить код из инструкции на сайте, затем Import → Import new profile. Название любое, например `SHTAB-SORTIR`.
4. Далее жмёте SELECT своего профиля и слева сверху огромная кнопка `Start modded`
5. Настраиваете игру, создаёте **нового** персонажа, жмёте начать, затем присоединиться и добавляете сервер. Адрес и пароль указаны в закрытой инструкции на сайте.
6. Дальше советую прочитать FAQ и поднастроить всё под себя
