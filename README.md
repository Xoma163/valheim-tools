# Valheim Admin

Панель управления игровым сервером: статус и игроки онлайн, карта, инструкция, FAQ и список модов.

## Локальный запуск

```powershell
uv sync
Copy-Item .env.example .env
```

Задайте в `.env`:
- `VALHEIM_SESSION_SECRET` — случайный секрет длиной не менее 32 символов;
- `VALHEIM_GAME_ADDRESS` — адрес игрового сервера;
- `VALHEIM_PROFILE_CODE` — код импорта сборки;
- `VALHEIM_GAME_PASSWORD` — игровой пароль;
- остальные параметры по примеру `.env.example`.

Запуск приложения:

```powershell
uv run python -m uvicorn valheim_admin.app:create_app --factory --host 127.0.0.1 --port 11110
```

Локальный адрес должен совпадать с `VALHEIM_PUBLIC_ORIGIN`. Используйте один worker: кэш и блокировки находятся в памяти процесса.

## Безопасность

- Авторизация выполняется обратным прокси по HTTPS, не приложением. Защитить нужно все страницы, API, карту и данные карты.
- Backend должен слушать только loopback; его нельзя открывать наружу.
- Адрес и код сборки подставляются из окружения. Игровой пароль отображается на главной странице и в инструкции.
- Изменения состояния сервера требуют POST и CSRF-токен. Демо-режим не управляет реальным сервером.
- `.env`, локальный `AGENTS.md` и инфраструктурные конфиги исключены из Git. Не включайте их в публикуемые архивы.
- Закрытые сведения о развёртывании хранятся в локальном `AGENTS.md`, который не отправляется на сервер.

## Проверка

```powershell
uv run python -m pytest -q
```

FAQ и инструкция находятся в шаблонах приложения. Версии и контрольные суммы модов — в `client-mods.lock.json`.
